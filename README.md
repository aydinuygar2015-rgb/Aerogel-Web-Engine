# Aerogel-Web-Engine
A lightweight and easy Web-based game engine.
 #What Is Aerogel?
 Aerogel is a lightweight game engine that supports webgpu,webgl and even html canvas(not using html canvas yet).And it supports js codes,meaning there is no limits!
 #How to use?
 Its too easy.It automaticly creates a 3D world.And,you can instantly access to the assets like player,ground,cube sphere and more.If you place player and a ground,you can make a playable 3D game!It has a cinematic camera and FPS camera.If you bored from these only walking 3D worlds,you can use JS files.Just create an JS file with right clicking the hierarchy text.After that,double click to the your js file and you can write codes!After writing,select an object from hierarchy or your world.then,drag your JS file into the Settings panel on the right.And boom!It works in game.
